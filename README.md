# Copy to AI — Full Page Screenshot

Розширення Chrome: знімає всю сторінку вниз і зберігає PNG або PDF, щоб закинути файл в AI. Поруч посадкова сторінка, з якої качається архів для встановлення вручну.

Версія розширення: 1.0.0. У Chrome Web Store ще не подано.

## Що вже зроблено

- Знімок усієї висоти сторінки. Липкі шапки і плаваючі кнопки в кадр не повторюються.
- Завантаження PNG, PDF однією сторінкою і PDF аркушами A4.
- Локальна перевірка на довгій сторінці: знімок вищий за вікно, початок і кінець на місці, обидва PDF відкриваються.
- Інструкція, як поставити собі через `chrome://extensions` і як пізніше опублікувати в магазині.

## Чого ще немає

- Акаунта розробника Chrome Web Store і самої публікації. Реєстрація коштує $5 один раз.
- Окремого архіву для магазину: у ньому `manifest.json` має бути в корені, не в папці `whole-page`.
- Дозвіл `debugger` магазин може відхилити. Тоді лишається запасний знімок прокруткою.

## Як поставити собі

1. Скачати `whole-page.zip` з посадкової сторінки і розпакувати.
2. У Chrome відкрити `chrome://extensions`, увімкнути режим розробника.
3. «Завантажити розпаковане» і вибрати папку `whole-page`.

На iPhone розширення не ставиться.

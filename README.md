# Page to PDF — Full Page Screenshot

Розширення Chrome: знімає сторінку, яку вже відкрито у вашому браузері — кабінет, аналітику, адмінку — і зберігає PNG або PDF, щоб дати файл в AI. Це знімок екрана на всю висоту, не вивантаження даних і не вхід замість вас. Посадкова сторінка англійською на `/`, українською на `/uk`. Дві кнопки: Chrome Web Store і архів `page-to-pdf.zip`.

Версія розширення: 1.0.13. У Chrome Web Store ще не подано.

## Що вже зроблено

- Знімок усієї висоти сторінки. Липка шапка і бічна колонка видимі зверху один раз і не повторюються нижче.
- Завантаження PNG, PDF однією сторінкою і PDF аркушами A4.
- Локальна перевірка на довгій сторінці: знімок вищий за вікно, початок і кінець на місці, обидва PDF відкриваються.
- Інструкція, як поставити собі через `chrome://extensions` і як пізніше опублікувати в магазині.

## Чого ще немає

- Акаунта розробника Chrome Web Store і самої публікації. Реєстрація коштує $5 один раз.
- Архів для Chrome Web Store лежить поруч із ручним: `page-to-pdf-1.0.13-cws.zip`, `manifest.json` у корені. У магазин ще не подано.
- Дозвіл `debugger` магазин може відхилити. Тоді лишається запасний знімок прокруткою.

## Як поставити собі

1. Скачати `page-to-pdf.zip` з посадкової сторінки і розпакувати.
2. У Chrome відкрити `chrome://extensions`, увімкнути режим розробника.
3. «Завантажити розпаковане» і вибрати папку `page-to-pdf`.

На iPhone розширення не ставиться.
